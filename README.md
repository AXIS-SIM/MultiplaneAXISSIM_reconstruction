# Multiplane AXIS-SIM Reconstruction

This repository provides the custom MATLAB reconstruction algorithm developed for the paper: *[Insert Paper Title Here]* (XX, 202X). 

Multiplane AXIS-SIM stands for Multiplane Axial Interference Speckle-engineered Structured Illumination Microscopy.

## Dataset
Due to file size limitations, the test dataset (representative microtubule raw images) is hosted on Figshare and can be downloaded from the following link:
[https://figshare.com/account/articles/33282306](https://figshare.com/account/articles/33282306)

## How to Run
To reproduce the reconstruction:
1. Download and unzip the Figshare dataset into the local `data` folder.
2. Open `MultiplaneAXISSIM_main.m` in MATLAB R2021b.
3. Run the script.

## Parameters
All parameters used to reproduce the cellular imaging experiments in the paper are pre-set in the provided code. 

## System Requirements
We recommend MATLAB R2021b. All required functions are included in the repository, and no additional installation is necessary.

## Notes
Please refer to our manuscript for detailed descriptions of the reconstruction algorithm and optical setup. If you encounter any issues with the code, please contact the corresponding author. 

Please note that the full datasets are not included in the public repository due to massive file size constraints. Complete datasets are available from the corresponding author upon reasonable request.
